Featured Projects

Emoji-Based Song Recommendation System (Java + XAMPP)

AI | Machine Learning | Java Backend | Database Integration

A smart recommendation engine that suggests songs based on users’ emoji inputs. This project translates emotional cues from emojis into mood-based song recommendations using Java, database queries, and emotion mapping techniques.

  • Features: Real-time emoji-to-song mapping using database queries. Supports multiple mood categories like happy, sad, romantic, and energetic. Responsive and interactive Java-based UI. Secure and efficient data storage via XAMPP MySQL.
  • Impact: Enhanced personalization in music recommendation systems through emotion-driven logic. Simplified user interaction by replacing text-based inputs with emojis. Encourages emotional connection between users and music.
  • Tech Stack: Java (Eclipse), XAMPP (MySQL), JDBC, SQL

A Predication of KAP in Hypothyroidism (Python/NLP)

Data Science | Visualization | NLP

A machine learning project designed to predict Knowledge, Attitude, and Practice (KAP) scores among individuals with hypothyroidism using advanced Natural Language Processing (NLP) techniques. The model analyzed text-based survey responses to assess awareness levels and health behavior patterns.

  • Tech Used: Python (TensorFlow, Keras, BERT, LSTM, Pandas, Matplotlib), NLP preprocessing, and data visualization tools.
  • Methodology: Text cleaning, tokenization, sentiment extraction, and embedding generation using BERT. Time-series trends were analyzed using LSTM for behavior prediction.
  • Impact: Helped identify key factors affecting patient awareness and attitudes toward hypothyroidism management, contributing to improved health education strategies.
