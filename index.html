A Predication of KAP in Hypothyroidism (Python/NLP)

Data Science | Visualization | NLP

A machine learning project designed to predict Knowledge, Attitude, and Practice (KAP) scores among individuals with hypothyroidism using advanced Natural Language Processing (NLP) techniques. The model analyzed text-based survey responses to assess awareness levels and health behavior patterns.

  • Tech Used: Python (TensorFlow, Keras, BERT, LSTM, Pandas, Matplotlib), NLP preprocessing, and data visualization tools.
  • Methodology: Text cleaning, tokenization, sentiment extraction, and embedding generation using BERT. Time-series trends were analyzed using LSTM for behavior prediction.
  • Impact: Helped identify key factors affecting patient awareness and attitudes toward hypothyroidism management, contributing to improved health education strategies.
